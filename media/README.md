## Footage / 画面来源

Robot footage was recorded in MuJoCo using this project's released balance-v6 policy and native C++ controller. Lift and free-fall scenes run the firmware detectors against simulated sensors with illustrative actuator integration; they do not establish additional hardware validation. The network graphic is schematic and the training chart uses published evaluation records.

机器人画面采用本项目发布版 balance-v6 策略与原生 C++ 控制器在 MuJoCo 中录制。离地、自由落体镜头使用固件检测代码、仿真传感器和演示性的执行器接入，不构成新增实机验证。网络图为示意，训练图取自发布的评估记录。

CAD visuals retain the [CC BY-NC 4.0](../training/models/cad/LICENSE) terms of the source meshes. The code's Apache-2.0 license does not replace the licenses of the media assets below. See [NOTICE.md](../NOTICE.md).
